        How it works

        Four chapters.

        Anyone can start a coin for a channel. Only the channel can take the money out.

        0:00

        Paste a channel

        Drop in any YouTube channel link and set a goal, like New camera, 8 SOL. Add stages if the video needs more.

        0:15

        The coin trades on pump.fun

        Creator fees from every buy and sell go to that channel's vault. Not to whoever launched it.

        0:30

        The goal fills

        Each stage fills like a progress bar. When one is fully funded, the channel can claim it and the next stage starts.

        0:45

        The creator claims

        No sign-up first. They put a one-time code like tp-7F3K-92 in the channel description, connect a wallet and withdraw.
